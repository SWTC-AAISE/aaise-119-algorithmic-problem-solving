From a demo folder, run:

```powershell
py -3.14 main.py
py -3.14 test_demo.py
```

Keep console_style.py beside the application. Use menu option 1 for the report,
2 for the teaching walkthrough, and 0 to exit. Optional main2.py companions
provide fuller comments; main.py is the uncluttered version. They are alternative
views of the same demo, not extra assignments.

Target runtime: Python 3.14.6; verified locally on 3.14.7. No external packages.
Thursday's optional_js folder separates HTML, CSS, and JavaScript and opens in
a browser without a server. Tests remain separate from application output.
