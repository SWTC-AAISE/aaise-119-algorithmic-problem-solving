# 10-152-119 Algorithmic Problem Solving

Student-facing course materials for Introduction to Algorithms.
Python is the primary language; selected demos include optional browser-based JavaScript examples.

## Student Workflow

1. Create one public repository for this class and add your instructor as collaborator.
2. Develop locally, commit regularly, and organize complete submissions in the assigned week folders.
3. For paired assignments, develop in a separate shared repository, then copy the completed application into your own class repository and add your personal README notes.
4. Submit **your own class repository URL** in Schoology and identify the assignment folder.

Start with [GitHub setup and submission](PreCourse_Setup/GitHub_Class_Repository_and_Submission_Guide.md)
and [paired programming](PreCourse_Setup/Paired_Programming_and_Assignment_Submission_Guide.md).

## Course Map

| Week | Focus |
| --- | --- |
| 01 | Precision, correctness, testing, and controlled changes |
| 02 | Big-O, growth, and workload comparisons |
| 03 | Data structures, queues, undo, and state |
| 04 | Search, sorting, and valid pipelines |
| 05 | Recursion, iteration, greedy strategies, and memoization |
| 06 | Graph models, traversal, and routes |
| 07 | Similarity, ranking, and integrity |
| 08 | Synthesis and individual assessments |
